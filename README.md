# Домашнее задание к работе 2

## Условие задачи

Человеку нужно съездить из Лондона в расположенный в 390 милях Эдинбург. Он может ехать на автомобиле марки “Роллс-Ройс” либо на автомобиле марки “Форд Эскорт”. “Роллс-Ройс” расходует 1 галлон бензина на каждые 15 миль пути. “Форд-Эскорт” расходует 1 галлон бензина на каждые 36 миль пути. Сколько будет стоит поездка в Эдинбург на “Роллс-Ройсе”, если стоимость 1 галлона бензина составляет **x** фунтов? Сколько денег он сбережет, если вместо этого поедет на машине марки “Форд-Эскорт”.

## 1. Алгоритм и блок-схема

### Алгоритм

1. **Начало**
2. Объявить константы:
    - distance = 390.0 (миль) — расстояние поездки.
    - rr_consumption = 15.0 (миль/галлон) — расход топлива Роллс-Ройса.
    - ford_consumption = 36.0 (миль/галлон) — расход топлива Форд-Эскорт.
3. Задать исходные данные:
    - x — цена 1 галлона бензина (фунтов).
4. Вычислить стоимость поездки на Роллс-Ройсе:
    - rr_gallons = distance / rr_consumption
    - rr_cost = rr_gallons * x
5. Вычислить стоимость поездки на Форд-Эскорт:
    - ford_gallons = distance / ford_consumption
    - ford_cost = ford_gallons * x
6. Вычислить общую сумму сбережений (экономию):
    - savings = rr_cost - ford_cost
7. Вывести результаты расчетов в консоль.
8. **Конец**
